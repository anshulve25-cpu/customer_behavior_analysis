# 🛒 Customer Behavior Dashboard

An end-to-end **Data Analytics & Business Intelligence** project built using **Python, PostgreSQL, SQL, and Power BI** to analyze customer shopping behavior and sales trends.

## 🚀 Project Highlights

* 📊 Interactive Power BI Dashboard
* 🐍 Data Cleaning & Preprocessing using Python
* 🗄️ PostgreSQL Database Integration
* 📈 SQL-Based Business Insights
* 👥 Customer Segmentation Analysis
* 💰 Revenue & Sales Trend Analysis

## 📌 Key Insights

* Revenue analysis by product category
* Customer purchase behavior tracking
* Subscriber vs Non-Subscriber comparison
* Age-group based sales distribution
* Product performance & review analysis

## 🛠️ Tech Stack

* **Python** (Pandas, NumPy)
* **PostgreSQL**
* **SQL**
* **Power BI**
